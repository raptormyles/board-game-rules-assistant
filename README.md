# Board Game Rules Assistant

An AI-assisted pipeline that turns photos of board game rulebooks into a structured rules reference and a short "if you know X, this is X + differences" comparison pitch — starting with a two-game pilot (Ticket to Ride, Catan).

See `PRD.md` for the full product requirements, the three project phases, and the Phase 1 design decisions (schema, storage format, metadata).

Raw rulebook photos and the generated per-game rulebook data are intentionally kept out of this repo (copyrighted source/derivative content) — see the PRD's risk log. This repo holds code, docs, and schema/design only. Generated rulebook data lives in the private companion repo: `board-game-rules-assistant-data`.
